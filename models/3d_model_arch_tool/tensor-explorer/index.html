FLOPs convention One multiply and one add count as 2 FLOPs. Projection and attention matrix products are counted; softmax, RoPE, normalization, gating and elementwise work are excluded unless explicitly stated.

Memory convention Weight and logical tensor sizes are exact from declared shapes and dtype. KV cache assumes each layer stores the compressed KV latent and the shared RoPE key. It excludes allocator overhead, temporary workspaces and implementation-specific padding.

Decode convention Query length is 1. Sequence length is interpreted as the existing KV cache length. Prefill uses query and key lengths equal to sequence length.
